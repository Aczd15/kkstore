# KKStore (PHP + MySQL)

Готовый учебный проект интернет-магазина и сервисного центра техники.

## Возможности

- Многостраничный сайт: главная, каталог, услуги, ремонт, аксессуары, новости, о нас, контакты.
- Каталог товаров с фильтрацией по категории, бренду и цене.
- Регистрация и авторизация пользователей.
- Роли: `customer`, `manager`, `admin`.
- Панель менеджера: отправка заявок на добавление товаров.
- Админ-панель: управление категориями, новостями, товарами, модерация заявок менеджеров.
- Современный минималистичный дизайн (темная тема).

## Запуск через XAMPP

1. Скопируйте проект в `htdocs`:
   - `C:\xampp\htdocs\kkstore`
2. Запустите Apache и MySQL в XAMPP Control Panel.
3. Создайте БД и таблицы:
   - Откройте `http://localhost/phpmyadmin`
   - Импортируйте файл `sql/schema.sql`
4. Проверьте настройки в `config/config.php`:
   - по умолчанию: host `127.0.0.1`, user `root`, password пустой, db `kkstore`
5. Откройте сайт:
   - `http://localhost/kkstore/index.php?page=home`

## Структура

- `index.php` — роутинг и обработка форм.
- `pages/` — страницы сайта.
- `templates/` — общий layout (header/footer).
- `includes/` — БД, авторизация, хелперы.
- `assets/` — стили и JS.
- `sql/schema.sql` — готовая MySQL схема и демо-данные.
